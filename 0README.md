Step-by-step tutorial on how to apply the Shader:
-------------------------------------------
Method 1️⃣:
1:Open Horizon launcher Android/PC

2:Go to the "Shaders" section.

3:Click on import file/shader

4:Choose HShade.hshader

5Open the game and apply the shaders. Have fun!

----------------------------------------------
Method 2️⃣:

1:Open Horizon launcher Android/PC 

2:Go to the "Files" section.

3:Next to "Shaders" click on Import file/Shaders

4:Select and choose HShade.hshader

5:Open the game and apply the shaders. Have fun!
---------------------------------------------
